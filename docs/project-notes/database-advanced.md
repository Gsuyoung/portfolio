# 오피스 용품 커머스 · DB 심화 · 확인 필요 메모

사이트에는 나가지 않는 작성 메모입니다. `src/content/projects/database-advanced.md` 에서 옮겨 왔습니다.

- 개인 역할은 "구매 영역 담당"으로 통일. 출고·배송·교환·환불은 구매와 연결된 흐름을 설명할 때만 언급하고 단독 담당으로 쓰지 않음. 실제 배송 과정 자체는 담당하지 않음.
- 진행 기록 날짜는 Notion 문서 기록 기준. 실제 시작·종료일과 다를 수 있음.
- (2026-10-19 사용자 확인) 성능 테스트: 주제는 날짜별·지역별 배송 상태 조회. JOIN 단순 쿼리 → MATCH → MATCH + 서브쿼리 순으로 개선. 실행 계획은 일부 Full Table Scan → 대부분 Index → 전부 Index + Covering Index. 710ms → 231ms. 가장 큰 테이블 약 50만 건이라 체감 차이는 크지 않았음. 2단계(MATCH만) 측정값은 받지 못함.
- (2026-10-19 사용자 확인) 트러블슈팅: 구매·출고에 트리거를 만들다 락(병목)이 생겨 경우에 따라 트리거와 프로시저를 나눠 써서 해결.
  - 원인 서술("트리거가 원래 쿼리와 같은 트랜잭션에서 돌며 락이 길어짐")과 나눈 기준("즉시 반영이 필요한 것은 트리거, 나머지는 프로시저")은 일반적인 동작을 바탕으로 정리한 문장 → 사용자 확인 필요.
