# CA2SA · 확인 필요 메모

사이트에는 나가지 않는 작성 메모입니다. `src/content/projects/ca2sa.md` 에서 옮겨 왔습니다.

- 옵션 조회·삭제 API는 현재 `MenuOptionController`, `MenuOptionService`, `MenuOptionMapper`에서 확인되지 않음. 다른 코드 경로나 당시 작업 이력을 확인한 후 구체적 구현 내역을 보완할 예정. (사이트의 역할 칸에는 "메뉴 옵션 CRUD 담당"으로 적혀 있으므로, 확인 결과에 따라 역할 문구를 맞출 것)
- 메뉴 옵션 조회·삭제의 실제 구현 위치 및 담당 내역은 추가 확인이 필요.
- 개발 기간은 본인 GitHub 커밋(2024.12.18 ~ 2025.01.02) 기준으로 기재. 실제 프로젝트 시작·종료일은 다를 수 있음.
- 구체적인 성과와 당시 해결했던 이슈는 추가 기록 확인 후 보완할 예정. 트러블슈팅이 생기면 frontmatter `troubleshooting` 에 넣으면 "검토 완료" 도장이 찍힘.
- "회고 · 다시 만든다면" 절은 실제로 수행한 트러블슈팅이 아니라 현재 공개 코드를 읽으며 발견한 개선 검토 사항임.
